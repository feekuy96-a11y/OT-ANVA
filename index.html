👥 รายชื่อพนักงาน

🔑 ผู้ใช้งานระบบ

เพิ่มผู้ใช้ใหม่: สร้างบัญชี (อีเมล+รหัสผ่าน) ที่ Supabase → Authentication → Users → Add user ก่อน แล้วกลับมาที่หน้านี้ กดรีเฟรช และกด "กำหนดสิทธิ์" ที่อีเมลนั้น (คนที่ยังไม่มีสิทธิ์จะเข้าใช้งานไม่ได้)
สิทธิ์: owner = ทุกอย่าง · manager = บันทึก/แก้/ลบ/จัดการพนักงาน · hr = บันทึก/แก้ OT และเบี้ยขยัน · viewer = ดู/พิมพ์/ส่งออก
อีเมลชื่อสิทธิ์สถานะเข้าสู่ระบบล่าสุดจัดการ

📥 นำเข้าข้อมูลเดิมจาก Google Sheet (ไฟล์ CSV)

ขั้นตอน: ทำสำเนา Google Sheet → ในแต่ละชีต เลือก ไฟล์ → ดาวน์โหลด → ค่าที่คั่นด้วยเครื่องหมายจุลภาค (.csv) แล้วนำเข้า ตามลำดับ 1 → 2 → 3 (พนักงานต้องมาก่อน) · ทุกครั้งต้อง "ตรวจสอบก่อน" (ยังไม่บันทึก) แล้วค่อย "ยืนยันนำเข้า"
นำเข้ารอบเดียวต่อชีต ถ้านำเข้าซ้ำ ระบบจะข้ามแถวที่เคยนำเข้าแล้ว (ดูจากเลขแถวใน Sheet) · แถวที่แปลงไม่ได้จะแสดงรายการให้เห็นทุกแถว ไม่ข้ามเงียบๆ
